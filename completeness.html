Three-player Kuhn poker · four-card deck · 312 leaves

Is the β⁠-family everything?

Szafron, Gibson and Sturtevant left it open whether their parameterized family contains all equilibria. Four earlier attempts here were inconclusive, and the verdict named the missing tool: branch-and-bound with partial-feasibility pruning. That tool now exists. Here is what it settles, and what it does not.

Proven

39 / 80

P1-betting branches that contain no equilibrium at all — by rigorous interval propagation, not search.

Certified

259

Exact equilibria found so far. Every one of them lies inside the family, to 2.3e⁠-14.

Still open

41

Branches where P1 bluffs at a frequency strictly between 0 and 1. Completeness is not proved.

01 — The short answer

Nothing outside the family — but the proof isn't closed

The support space of the P1-silent branch has been enumerated exhaustively for the first time. Of a 13% random sample of it, four fifths are proven to carry no equilibrium, and every equilibrium that does exist there reproduces Table 3 exactly — every identity, every payoff, the whole range of β. Separately, 39 of the 80 branches in which P1 bets are proven empty.

What is left is a genuine gap, not a formality: 41 branches in which P1 bluffs with interior probability, and 87% of the enumerated silent supports still being screened. P1's bet is not dominated — against loose enough opponents it gains up to +1.25 — so those branches cannot be waved away.

02 — The instrument

A box implies its own condition

The earlier searches enumerated support labels: each coordinate marked 0, 1, or interior. That has a defect. "Interior" has to be carried as the box [0,1], which contains both pure labels — so the branch "P1 bluffs card 1" silently re-does the entire problem. That redundancy is why the label search never terminated on the betting branches.

Dropping labels entirely fixes it. Work with a box per coordinate and let the box imply the Nash condition:

The bound underneath is interval propagation over the game tree, not term-by-term arithmetic on the 312-leaf sum. At a node with coordinate x ∈ [lo,hi] the value is a convex combination in x, so the interval is tight in that variable — term-by-term bounds throw away x + (1−x) = 1 and are far weaker. It collapses onto the exact gradient at a point to 5.6e⁠-17.

04 — The betting branches

Where P1 speaks, and where it can't

Branch on the labels of P1's four opening coordinates: 34 = 81 cells. One is the silent branch that holds the family. Thirty-four die on the very first fixed point of interval propagation, in milliseconds; five more fall to the full search.

The dead cells have structure, not scatter. P1 always betting the worst card kills 22 of its 27 branches outright, and every branch combining that with a21 ∈ {1, interior} is dead. The five proven by search all have P1 always betting card 2. What survives is exactly the interesting case: P1 bluffing at some frequency strictly inside (0,1).

05 — The algebra

Where β = max{b11, b21} actually comes from

Fixing the support structure the enumeration says is the only one carrying P1-silent equilibria and building the indifference equations symbolically over the 24-deal tree in exact rational arithmetic, the whole system is eight small polynomials:

du1/da33 = (2·b11 + 2·b21 − b41)/12            du2/db33 = (2·c11 + 2·c21 − 1)/12
du2/db11 = −(2·a33 − 1)/12                     du2/db41 = (a33 − c11 − c21)/12
du2/db21 = −(2·a33 + 2·b23·c11 − b23 − 1)/12   du3/dc21 = −(b11 + 2·b33 − b41 − 1)/12
du2/db23 = −(b21 − 1)(2·c11 − 1)/12
du3/dc11 = (2·b21·b23 − b21 − 2·b23 − 2·b33 + b41 + 1)/12

They read off almost by inspection. du2/db11 = 0 gives a33 = 1/2 on the spot — P1's call frequency at KBF is pinned by P2's willingness to bet card 1 and by nothing else. du1/da33 = 0 gives b41 = 2(b11+b21). du2/db33 = 0 gives c21 = 1/2 − c11.

And du2/db21 = 0, once a33 = 1/2 is substituted, collapses to a single product:

The factorisation that splits the family

b23 · (2·c11 − 1) = 0 — so either b23 = 0, or c11 = 1/2. There is no third option, and that is the whole of SGS's sub-family structure.

Each of those b33 expressions equals Table 3's single formula exactly — symbolic residual zero — once β is read as b21 in case A and b11 in cases B and C. Which gives the punchline:

Reading the max

β = max{b11, b21} is not a formula. It is two cases glued.

Sub-family A carries b11 ≤ b21 and produces β = b21; sub-family C carries b21 ≤ b11 and produces β = b11; B has them equal. The max in Table 3 is the one expression that covers all three — nothing in the algebra ever computes a maximum.

Conditional on the support structure, this is a proof of Table 3.

06 — Correction

c41 = 1 is not dominance-forced

One rigorous by-product: a single interval fixed point over the full 48-dimensional cube — no sampling, no interiority assumption — forces exactly the 21 values of the paper's Table 2, entry for entry. It does not force a 22nd.

An earlier pass in this project claimed c41 = 1 was also dominance-forced, "a small strengthening" of Table 2. It isn't. Set a22 = a32 = b23 = b33 = 0 alongside the Table 2 values: then du3/dc41 = 0 exactly, while the information set has reach 0.25. P3 holding card 4 wins the same two chips whether it bets and everyone folds or checks and takes the showdown. The old scan confined the other coordinates to [ε, 1−ε], which excludes exactly that profile — and an interiority-restricted scan cannot establish dominance. c41 = 1 belongs in Table 3, where SGS put it.

07 — What would close it

The remaining gap, stated honestly

  • 41 betting branches. All have P1 bluffing at an interior frequency. The partition-based search handles them without the redundancy that stalled the label search; they are running, not resolved.
  • 87% of the silent supports. The remaining 2,645,358 enumerated patterns are being screened now. Every completed block so far has come back the same way: ~80% proven infeasible, the rest either infeasible or a family point.
  • The solver stage is a search, not a decision procedure. A pattern the Levenberg–Marquardt stage fails on is not thereby proved infeasible. Only the interval-bisection stage issues proofs, and it settled 80.2%. Closing the remaining 20% needs the bisection driven deeper, or an exact solver on each surviving system.

The honest statement is stronger than the old one but the same in kind: no equilibrium outside the SGS family exists anywhere the search has looked — and the search has now looked exhaustively at the support level.
