  d u / d b31 = (1/24) * (3/2, -5/2, 1) = (1/16, -5/48, 1/24)
              = (+0.062500, -0.104167, +0.041667)

  engine, central finite difference (h=1e-5): (+0.06250000, -0.10416667, +0.04166667)
  engine, exact multilinear derivative      : (+0.06250000, -0.10416667, +0.04166667)
  hand calculation                          : (+0.06250000, -0.10416667, +0.04166667)
  max discrepancy: 2.702e-12

  zero-sum check:  du1 + du2 + du3 = 1/16 + -5/48 + 1/24 = 0

  A = P2  =>  B = P3, C = P1   (cyclic convention)
  rho = -(du_C/de)/(du_A/de) = -(du_1)/(du_2) = -(1/16)/(-5/48) = 3/5 = 0.6000
  complementary share  rho_{P2->P3} = -(du_3)/(du_2) = 2/5 = 0.4000
  the two shares sum to 1, as they must (zero sum).

  P2 pays 2.5/24 chips per unit of eps; 1.5/24 (60%) of that lands on
  P1 and 1.0/24 (40%) on P3.  The denominator is strictly negative, so
  rho is well defined HERE -- and it stays exactly 3/5 over the whole
  family (see the sweep).
